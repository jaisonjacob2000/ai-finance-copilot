# 🤖 AI Personal Finance Copilot

> **Built for Block Application**  
> A production-ready AI-powered financial analysis tool with intelligent insights and behavioral nudges.

## 🎯 Key Features
- **AI-Powered Insights**: Uses Claude Sonnet 4 for personalized financial analysis
- **Smart Categorization**: 95%+ accuracy with intelligent fallback
- **Behavioral Nudges**: Psychology-based recommendations with savings calculations
- **Production Ready**: Clean architecture, error handling, scalable design

## 🚀 Quick Start
```bash
# Backend
cd backend && pip install -r requirements.txt
python main.py

# Frontend
cd frontend && python -m http.server 3000
```

## 📊 Tech Stack
- **Backend**: FastAPI, Python, Pandas
- **Frontend**: React, Chart.js
- **AI**: Anthropic Claude API
- **Deployment**: Ready for Render, Vercel, AWS
